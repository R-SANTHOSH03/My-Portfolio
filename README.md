# 🌐 Personal Portfolio Website

A modern and responsive personal portfolio website built to showcase my skills, projects, experience, and contact information.

## 🚀 Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- Material UI (MUI)
- Framer Motion

### Backend
- Node.js
- Express.js
- Resend Email API
- Nodemailer
- CORS
- Dotenv

## ✨ Features

- Responsive Design
- Modern UI
- Smooth Animations
- Project Showcase
- Skills & Experience
- Contact Form
- Email Integration with Resend
- Fast Performance

## 📂 Project Structure

```
My-Portfolio/
├── Frontend/
├── Backend/
└── README.md
```

## 🛠️ Installation

Clone the repository:

```bash
git clone https://github.com/R-SANTHOSH03/My-Portfolio.git
```

Install frontend dependencies:

```bash
cd Frontend
npm install
npm run dev
```

Install backend dependencies:

```bash
cd Backend
npm install
npm run dev
```
